# DAYBOARD — журнал изменений

## 1.0.1 — 28 октября 2026

- Ctrl+N: перехват сочетания в capture-фазе окна; повторное создание после Enter.
- Kanban: включён HTML5 Drag & Drop в Windows WebView2 через `dragDropEnabled: false` (Tauri v2).
- Kanban/Неделя: полноценное перемещение карточек мышью, в том числе порядок внутри колонки/дня.
- Даты: собственный минималистичный календарь с темной темой; открывается нажатием на строку целиком.
- Ручной ввод даты `ДД.ММ.ГГГГ` или `ГГГГ-ММ-ДД`, времени `ЧЧ:ММ`, проверка корректности, выбор месяца, «Сегодня», очистка.
- Запланированная дата, дедлайн, напоминание сохраняются в прежнем формате без миграции SQLite.
- В тестах проверяются 3 последовательных Ctrl+N, DnD статусов/дней/порядка, календарь и режим виджета.

**Ограничение:** тесты Chromium используют имитацию Tauri IPC. До запуска GitHub Actions и проверки на настоящей Windows 11 бинарник 1.0.1 не считается протестированным на Windows.
